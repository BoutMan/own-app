On démarre le développement de l'app mobile **Own**. Tout le projet est dans ce dossier.

1. Lis `CLAUDE.md` en entier, puis `docs/spec-fonctionnelle.md` et `design/screens.md`.

**Ne code rien pour l'instant.** Réponds-moi en français avec :

- ta validation ou tes objections sur la stack proposée dans `CLAUDE.md` ;
- l'arborescence du projet que tu proposes ;
- le modèle de données (saison, blocs, séances, exercices, séries enregistrées, marqueurs, tests, cycle) ;
- le découpage en jalons, avec pour chacun ce que je pourrai tester moi-même à la fin ;
- les questions qui te bloquent vraiment (pas plus de 5).

Une fois qu'on est d'accord, on attaque le jalon 0 (fondations + composants + écran kitchen-sink).
